# memory-game


Memory Game is a card matching game built with HTML, CSS, and JavaScript.

The game contains 16 cards with 8 matching pairs. The goal is to find all pairs using as few moves as possible.

## Features

- 16 cards / 8 pairs
- Random card shuffle
- Marvel character cards
- Moves counter
- Pairs counter
- New Game
- Win modal
- Leaderboard
- Top 10 results saved in Local Storage
- Responsive design

## How to run locally

1. Clone the repository:

   git clone https://github.com/DaniyalBeisenbay/memory-game.git

2. Open the project folder.

3. Open `index.html` in your browser.
